# BB Global Stores downloads

Official desktop installers for BB Global Stores.

**[Download and setup instructions](https://www.bbglobalstores.com/downloads)**

Windows releases support Windows 10 and Windows 11 on 64-bit PCs. Sign in with your existing BB Global account. An internet connection is needed for the first sign-in and catalogue download.

## Pilot releases

The current Windows installer is an unsigned pilot. Windows may display an unknown publisher or reputation warning. If installation is blocked, use the [browser edition](https://www.bbglobalstores.com/auth) or contact support. Automatic desktop updates are not enabled; check the official Downloads page for new versions.

Each release includes the installer and its SHA-256 checksum. Test your receipt printer and camera with the shop before a wider rollout.

Support: support@bbglobalstores.com

This repository distributes installers and release notes. The application source is maintained separately.
